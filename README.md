# 🧹 AI 파일 청소기 (Mac)

Mac 저장 공간을 사각형 지도로 보여 주고, 구독 중인 AI(Claude Code · Codex · Gemini)의 설명을 받아 안 쓰는 파일을 정리하는 앱입니다. 지운 것은 휴지통을 거치므로 되돌릴 수 있습니다.

이 저장소는 **내려받기 전용**입니다.

## 설치

1. [최신 릴리스](https://github.com/soleil0430/diskmap-releases/releases/latest)에서 `AI-file-cleaner-<버전>.dmg` 를 받습니다
2. dmg 를 열고 **AI 파일 청소기** 를 **응용 프로그램** 폴더로 끌어다 놓습니다
3. 응용 프로그램에서 앱을 엽니다. "확인되지 않은 개발자" / "열 수 없습니다" 창이 뜨면 **완료** → 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래 **그래도 열기** → 암호 입력. 처음 한 번만 하면 됩니다
   (무료로 나눠 주는 앱이라 Apple 유료 개발자 서명이 없어서 뜨는 창입니다)

Apple 칩 · Intel Mac 모두 되고, macOS 12 이상에서 돌아갑니다. Python 은 앱 안에 들어 있어 따로 설치할 필요가 없습니다.

## 업데이트

새 버전이 나오면 앱 메인 화면에 **새 버전이 있습니다 — 업데이트** 상자가 뜹니다. 누르면 몇 초 안에 새 버전으로 다시 켜집니다. 다시 설치하거나 권한을 다시 줄 필요가 없습니다.

## 개인정보

파일 내용은 내 컴퓨터 밖으로 보내지 않습니다. AI 분석을 누를 때만 폴더·파일 이름과 크기가 쓰고 있는 AI 서비스로 전달됩니다. 업데이트 확인 때는 이 저장소의 버전 번호 파일만 받아 옵니다.
